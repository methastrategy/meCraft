# @mecraft/studio-shell

> **Universal Window Frames, Studio Docks & Topbars for Desktop & Web**  
> *Category: SHARED PACKAGE · Status: Stable v1.0.0 · Suite: meCraft*

---

## 📌 Overview
`@mecraft/studio-shell` standardizes the desktop and web UI chrome across all 15 meCraft studios.

### Key Capabilities:
1. **Window Topbar:** Custom window controls (Minimize, Maximize, Close) with Tauri window drag regions.
2. **Studio Dock & Navigation:** Uniform application switcher, status indicators, and keyboard shortcut overlays.
3. **Modal & Dialog Controller:** Standardized modal popups, file pickers, and alerts conforming to the Neue Klasse design system.
