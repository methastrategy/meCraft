ดาวน์โหลด mecraft-hub.msi
ดูประวัติรุ่นบน GitHub ↗

1. ดาวน์โหลด

ใช้ปุ่มดาวน์โหลดเมื่อ MSI รุ่นเผยแพร่พร้อมให้ใช้งาน

2. ติดตั้ง

เปิดไฟล์ mecraft-hub.msi และทำตามขั้นตอนของ Windows

3. เปิด Library

เลือกดูแอปใน meCraft และติดตั้งเฉพาะแอปที่พร้อมใช้งาน
