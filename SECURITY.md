# Security & Privacy Policy — meCraft

## 🛡️ 100% In-Browser Privacy Guarantee

meCraft is architected from the ground up as a private-by-design, client-side engineering ecosystem:

1. **Zero-Server-Upload Invariant:**
   - All document operations (merging, splitting, compressing, encrypting, and rendering) execute entirely inside your local device's memory and browser sandbox (CPU/GPU, Web Workers, WebAssembly).
   - Document bytes, page images, and text content are **never** transmitted to remote servers.

2. **Offline-First Resilience:**
   - Both the Web Progressive Web App (PWA) and the Windows Desktop binary operate fully offline without an internet connection.

3. **No Hidden Telemetry:**
   - We do not log, track, or collect any personal identifiable information (PII), document filenames, or document contents.

---

## 🔒 Reporting a Vulnerability

If you discover a security vulnerability or potential privacy leakage in meCraft, please report it responsibly:

- **Email:** `methastrategy@gmail.com`
- **Subject:** `[SECURITY] meCraft Vulnerability Report`

Please include:
- A description of the vulnerability and affected component.
- Reproduction steps or proof-of-concept.
- Any potential impact on client-side sandboxing.

We appreciate your responsible disclosure and will address validated reports promptly.
