# meDoc

> **Distraction-Free Rich Document & Typography Processor**  
> *Category: DOCUMENT · Status: Draft / In-Development · Suite: meCraft*

---

## 📌 Overview
Clean, beautiful document editor with semantic styling, table generators, offline privacy, and docx synchronization.

- **Inspired By:** Microsoft Word / WordCraft (storytold/wordcraft)
- **Supported File Formats:** `.docx`, `.doc`, `.rtf`, `.odt`
- **Privacy Standard:** 100% In-Device RAM Privacy. All compute executes on local client resources with zero telemetry.
- **Distribution:** Downloaded, installed, and launched exclusively via **meCraft Launcher** (`meCraft.exe`).

---

## 🛠️ Architecture Seams
- **Core Engine:** TypeScript / Rust WebAssembly
- **Native Desktop Shell:** Tauri v2 Windows Shell
- **Windows File Association:** `%LOCALAPPDATA%\meCraft\apps\medoc\medoc.exe`
