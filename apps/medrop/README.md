# @mecraft/medrop — meDrop Radial Transfer

> **Zero-Window Radial Drag-and-Drop File Converter HUD**  
> *Category: UTILITY · Status: Stable v1.0.0 · Suite: meCraft*

---

## 📌 Overview
meDrop is a lightweight, distraction-free radial converter HUD designed for ultra-fast drag-and-drop file transformations and cross-studio handoffs.

- **Radial Conversion Ring:** Drag any file onto the HUD ring to instantly trigger target conversion options.
- **Instant MIME Recognition:** Automatically identifies images, documents, audio, and archives.
- **ClipBus Broadcast:** Pipes converted assets into running meCraft studio windows without saving intermediate disk junk.

---

## 🛠️ Tech Stack & Distribution
- **Core Engine:** TypeScript, `@mecraft/core-bridge`, `@mecraft/ui-tokens`
- **Native Desktop Shell:** Tauri v2 Windows Shell
- **Distribution:** Web Studio (`/medrop/`) and standalone Windows installer `meDrop_1.0.0_x64-setup.exe`.
