# 💻 meIDE — Private-First AI IDE & Code Copilot

> Part of the **meCrafts Ecosystem** · 100% In-Device Memory Execution · MIT Open-Source

**meIDE** is a dedicated, next-generation AI Integrated Development Environment built for Windows and Web. Inspired by VS Code and Windsurf, meIDE provides an ultra-fast, luxury OLED Dark development cockpit where every keystroke, file buffer, and AI interaction executes strictly inside your machine's local RAM.

---

## ⚡ Key Features

- **📁 Real Folder & File System Access:** Open, traverse, and edit disk folders with `window.showDirectoryPicker()` or native file system dialogs.
- **📑 Multi-Tab Workspace:** Full multi-tab editing with dirty state indicators (`●`), gutter line numbers, and instant `Ctrl+S` saving.
- **📐 Mathematical Markdown & Equation Preview:** Real-time side-by-side rendering with KaTeX/LaTeX math syntax (`$$...$$` and `$...$`), tables, and code fences.
- **📟 Integrated Terminal CLI:** Built-in shell supporting `help`, `stats`, `version`, `ls`, `clear`, and `echo`.
- **🛡️ In-Device RAM AI Copilot:** Offline AI code assistance for explanation, summarization, formatting, security auditing, and refactoring without cloud telemetry.
- **🔒 100% Client-Side Privacy:** Zero telemetry, zero external tracking, zero prompt logging.

## ⌨️ Keyboard Shortcuts

| Shortcut | Description |
| :--- | :--- |
| `Ctrl + S` | Save active file to disk |
| `Ctrl + O` | Open local file |
| `Ctrl + K Ctrl + O` | Open workspace directory |
| `Ctrl + N` | Create new in-memory file |
| `Ctrl + B` | Toggle left explorer |
